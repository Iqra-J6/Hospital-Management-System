# Hospital Management System

A Python-based Hospital Management System developed as part of a first-year project. The system simulates core hospital operations including patient management, doctor management, and administrative functions.

---

## 📌 Overview

This system is designed to manage key hospital processes such as registering patients, managing doctor information, and handling administrative tasks. It follows a structured programming approach and demonstrates foundational principles.

The project includes separate modules for different roles within the hospital system, ensuring clear separation of responsibilities and improved code organisation.

---

## ✨ Features

- Patient registration and management
- Doctor profile management
- Admin login and control functions
- Basic hospital workflow simulation
- Structured data handling across multiple modules
- System testing documentation included

---

## 🧩 Modules

The system is divided into the following Python files:

- `Main.py` → Entry point of the application  
- `Patient.py` → Handles patient-related data and operations  
- `Doctor.py` → Manages doctor information and functionality  
- `Admin.py` → Controls administrative access and actions  

---

## 📊 System Design & Documentation

This project includes supporting design and analysis materials:

- `ADT.drawio` → Abstract Data Type / system structure diagram  
- `admin-login.drawio` → Admin authentication flow design  
- `Software Implementation Checklist.docx` → Development planning and tracking  
- `test case.docx` → System testing scenarios and validation
